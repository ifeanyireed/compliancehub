01 Architecture, Topologies & Pre-Configured Test Personas

ComplianceHub.ng employs a decoupled architecture consisting of a Next.js 16 frontend workspace and a high-throughput Go API backend communicating with a multi-tenant Neon Lakebase PostgreSQL instance and Cloudinary Evidence Vault.

Frontend Topology (Next.js 16 Turbopack)

• Local Dev URL: http://localhost:3000 (or :3003)
• Routing Style: Next.js App Router with trailingSlash: true
• RBAC Guard: RoleGuard context with dynamic role emulation
• Entity Switcher: Floating Temporary Entity Switcher Bar

Backend Topology (Go 1.23+ Core API)

• API Port: :8080 (dynamic Render $PORT)
• Health Check: /api/health and /health (Status 200)
• Neon Postgres: Auto-scaling serverless pool (AWS us-east-2)
• Cloudinary Vault: S3-compatible evidence storage (yugcjpau)
